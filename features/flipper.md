# Flipper Zero games

Games from the Flipper Zero multitool. A source-compatible layer provides the Flipper SDK's drawing, input and storage calls.

Upstream: [Flipper Zero firmware](https://github.com/flipperdevices/flipperzero-firmware). Our layer is in [`apps/plugins/flipper`](https://github.com/jaydens-tasty-slop/rockbox/tree/master/apps/plugins/flipper).
