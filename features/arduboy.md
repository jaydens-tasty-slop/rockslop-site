# Arduboy games

Games for the Arduboy, a credit-card handheld with a 128x64 black-and-white screen. A compatibility layer runs the original Arduino C++ sketches as ordinary Rockbox plugins, one per game.

Upstream: [Arduboy](https://arduboy.com) and [Arduboy2 library](https://github.com/MLXXXp/Arduboy2). Our layer is in [`apps/plugins/arduboy`](https://github.com/jaydens-tasty-slop/rockbox/tree/master/apps/plugins/arduboy).
