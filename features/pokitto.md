# Pokitto games

Games for the Pokitto, a small colour handheld. A layer written against PokittoLib runs the games unchanged.

Upstream: [PokittoLib](https://github.com/pokitto/PokittoLib). Our layer is in [`apps/plugins/pokitto`](https://github.com/jaydens-tasty-slop/rockbox/tree/master/apps/plugins/pokitto).
