# About

I love rockbox but thought it was a shame there was no in-production, cheap MP3 players supported.

One day I decided to plug a cheap MP3 player into my computer and ask an LLM to reverse engineer it to port Rockbox. Things spiralled from there.

The goal of this project is that every cheap mp3 player that could run Rockbox can, through the power of agents with infinite patience. I don't let pesky things like "reading the code the agent spits out" slow me down around here, but I do aim to make it prove to my satisfaction that it works before releasing it.

My philosophy is that a vibecoded port is better than no port, and I don't think anyone would have done this otherwise. This probably makes upstreaming these changes a non-starter.

Huge thanks to every single Rockbox contributor over the years!
